1. Why HashMap allows one null key?

Answer

HashMap allows only one null key because internally it stores the null key in bucket index 0.

Normally HashMap calculates bucket index using:

hash(key) % capacity

But if the key is null, there is no hashCode(), so Java directly stores it in bucket 0.

Example

Map<String, String> map = new HashMap<>();

map.put(null, "Java");
map.put(null, "Spring");   // replaces previous value

System.out.println(map);

Output

{null=Spring}

✔ Only one null key allowed because keys must be unique.

2. Why TreeSet does not allow null?

Answer

TreeSet does not allow null because it uses sorting (Comparable / Comparator) internally.

It compares elements using:

compareTo()

If null is inserted, Java cannot compare:

null.compareTo()

This causes NullPointerException.

Example

Set<Integer> set = new TreeSet<>();

set.add(10);
set.add(null);   // throws exception

Output

NullPointerException

✔ Because TreeSet uses Red-Black Tree for sorting.

3. How HashMap works internally?

Core concept

HashMap uses:

Hashing + Bucket + LinkedList / Red Black Tree

Step-by-step

1️⃣ When put(key,value) is called

hashCode() → calculate hash

2️⃣ Java converts hash into bucket index

index = hash & (capacity - 1)

3️⃣ Data stored in bucket

Structure:

Bucket → Node(key,value,hash,next)

4️⃣ If collision occurs

Java 7 → LinkedList

Java 8 → LinkedList → Red Black Tree (if >8 elements)


Diagram

HashMap
   |
      |---- Bucket[0]
         |---- Bucket[1] → Node → Node → Node
            |---- Bucket[2]
               |---- Bucket[3]

               Example

               Map<Integer,String> map = new HashMap<>();

               map.put(1,"Java");
               map.put(2,"Spring");
               map.put(3,"Microservices");

               Average Time Complexity

               O(1)

               Worst Case

               O(log n) (Java 8 Tree)

               4. Difference between Iterator and ListIterator

               Feature	Iterator	ListIterator

               Direction	Forward only	Forward + Backward
               Collection support	All collections	Only List
               Add operation	Not allowed	Allowed
               Replace	Not allowed	Allowed


               Iterator Example

               List<String> list = new ArrayList<>();
               list.add("Java");
               list.add("Spring");

               Iterator<String> it = list.iterator();

               while(it.hasNext()) {
                       System.out.println(it.next());
               }


               ---

               ListIterator Example

               List<String> list = new ArrayList<>();

               ListIterator<String> it = list.listIterator();

               while(it.hasNext()) {
                       System.out.println(it.next());
               }

               while(it.hasPrevious()) {
                       System.out.println(it.previous());
               }

               ✔ ListIterator can move both directions.

               5. Fail Fast vs Fail Safe Iterator

               Fail Fast Iterator

               If collection is modified while iterating, it throws:

               ConcurrentModificationException

               Example

               List<Integer> list = new ArrayList<>();
               list.add(1);
               list.add(2);

               Iterator<Integer> it = list.iterator();

               while(it.hasNext()) {
                       list.add(3);   // modification
               }

               Output

               ConcurrentModificationException

               Examples

               ArrayList

               HashMap

               HashSet



               ---

               Fail Safe Iterator

               Fail safe iterators work on a copy of collection, so modification is allowed.

               Example

               CopyOnWriteArrayList<Integer> list = new CopyOnWriteArrayList<>();

               list.add(1);
               list.add(2);

               for(Integer i : list){
                       list.add(3);  // allowed
               }

               Examples

               CopyOnWriteArrayList

               ConcurrentHashMap

✅ Step-by-step Implementation

1. Add a processed flag to Employee entity

package com.example.springbatchjpah2.model;

import jakarta.persistence.*;

@Entity
@Table(name = "employee")
public class Employee {
    @Id
    private int id;
    private String name;
    private String dept;
    private boolean processed = false;  // ✅ new field

    public int getId() { return id; }
    public void setId(int id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public String getDept() { return dept; }
    public void setDept(String dept) { this.dept = dept; }

    public boolean isProcessed() { return processed; }
    public void setProcessed(boolean processed) { this.processed = processed; }

    @Override
    public String toString() {
        return "Employee [id=" + id + ", name=" + name + ", dept=" + dept + ", processed=" + processed + "]";
    }
}

2. Update the Repository

Add a custom query to fetch only unprocessed employees, limiting to 1 result.

package com.example.springbatchjpah2.repository;

import com.example.springbatchjpah2.model.Employee;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;

import java.util.Optional;

public interface EmployeeRepository extends JpaRepository<Employee, Integer> {

    @Query(value = "SELECT * FROM employee WHERE processed = false LIMIT 1", nativeQuery = true)
    Optional<Employee> findNextUnprocessed();
}

3. Update the BatchConfig (reader + writer)

We’ll use a custom ItemReader (since we want one record each run).

package com.example.springbatchjpah2.config;

import com.example.springbatchjpah2.model.Employee;
import com.example.springbatchjpah2.repository.EmployeeRepository;
import org.springframework.batch.core.*;
import org.springframework.batch.core.configuration.annotation.*;
import org.springframework.batch.item.*;
import org.springframework.batch.item.support.builder.*;
import org.springframework.context.annotation.*;
import org.springframework.transaction.PlatformTransactionManager;

import java.util.Optional;

@Configuration
@EnableBatchProcessing
public class BatchConfig {

    @Bean
    public ItemReader<Employee> reader(EmployeeRepository repository) {
        return new ItemReader<>() {
            @Override
            public Employee read() {
                Optional<Employee> next = repository.findNextUnprocessed();
                return next.orElse(null); // null = no more items to read
            }
        };
    }

    @Bean
    public ItemProcessor<Employee, Employee> processor() {
        return emp -> {
            emp.setName(emp.getName().toUpperCase());
            emp.setProcessed(true);  // ✅ mark as processed
            return emp;
        };
    }

    @Bean
    public ItemWriter<Employee> writer(EmployeeRepository repository) {
        return employees -> {
            employees.forEach(e -> {
                repository.save(e);  // ✅ update processed flag
                System.out.println("Processed: " + e);
            });
        };
    }

    @Bean
    public Step step(JobRepository jobRepository,
                     PlatformTransactionManager transactionManager,
                     ItemReader<Employee> reader,
                     ItemProcessor<Employee, Employee> processor,
                     ItemWriter<Employee> writer) {

        return new StepBuilder("step1", jobRepository)
                .<Employee, Employee>chunk(1, transactionManager) // one record
                .reader(reader)
                .processor(processor)
                .writer(writer)
                .build();
    }

    @Bean
    public Job job(JobRepository jobRepository, Step step1) {
        return new JobBuilder("employeeJob", jobRepository)
                .start(step1)
                .build();
    }
}

4. Scheduler (same as before)

In your main application class:

package com.example.springbatchjpah2;

import org.springframework.batch.core.*;
import org.springframework.batch.core.launch.*;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.scheduling.annotation.*;

import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@SpringBootApplication
@EnableScheduling
public class SpringBatchJpaH2Application {

    @Autowired
    private JobLauncher jobLauncher;
    @Autowired
    private Job job;

    public static void main(String[] args) {
        SpringApplication.run(SpringBatchJpaH2Application.class, args);
    }

    @Scheduled(fixedRate = 10000)
    public void performJob() throws Exception {
        Map<String, JobParameter<?>> params = new HashMap<>();
        params.put("time", new JobParameter<>(new Date().getTime(), Long.class));

        JobParameters jobParameters = new JobParameters(params);
        System.out.println("\nRunning job at: " + new Date());
        jobLauncher.run(job, jobParameters);
    }
}

5. Sample Data Loader

package com.example.springbatchjpah2;

import com.example.springbatchjpah2.model.Employee;
import com.example.springbatchjpah2.repository.EmployeeRepository;
import org.springframework.boot.CommandLineRunner;
import org.springframework.stereotype.Component;

@Component
public class DataLoader implements CommandLineRunner {
    private final EmployeeRepository repository;

    public DataLoader(EmployeeRepository repository) {
        this.repository = repository;
    }

    @Override
    public void run(String... args) {
        repository.save(new Employee(){{
            setId(1); setName("Narsing"); setDept("IT");
        }});
        repository.save(new Employee(){{
            setId(2); setName("Ravi"); setDept("HR");
        }});
        repository.save(new Employee(){{
            setId(3); setName("Kiran"); setDept("Finance");
        }});
    }
}
